# MediCare Plus - Modern Clinic & Hospital Website

A modern, responsive, single-page website for **MediCare Plus**, a private clinic and hospital. Built with clean, medical-grade aesthetics, subtle micro-interactions, and accessibility in mind.

## 🌟 Features

- **Top Bar & Sticky Navbar**: Contact information, operating hours, frosted-glass scroll effect, pulsating brand logo, and responsive mobile hamburger menu.
- **Hero Section**: Medical-grade color palette (sky blues, calming teals, crisp whites), clinical hero photography, and 3 floating interactive badges (including a live cardiac rhythm monitor with animated heartbeat pulse).
- **Why Choose Us**: 4 feature cards highlighting 24/7 Emergency, Expert Doctors, Modern Equipment, and Cashless Insurance.
- **Comprehensive Services Grid**: Interactive cards for Cardiology, Neurology, Pediatrics, Orthopedics, Dental Care, and General Health Checkups.
- **Specialist Doctors Carousel**: Touch-enabled, auto-playing carousel showcasing physicians with ratings and direct "Book Appointment" buttons that pre-populate the appointment form.
- **Medical Departments Grid**: 8 specialized clinical divisions with hover-activated color gradients.
- **Animated Stats Counter**: Scroll-triggered counting numbers with cubic easing (Years of Experience, Patients Treated, Expert Doctors, Healthcare Awards).
- **Patient Testimonials Slider**: Patient recovery stories with 5-star rating stars, auto-advance, and navigation controls.
- **Online Appointment Booking Form**: Live input validation, minimum date restriction (preventing past dates), department picker, interactive loading state, and booking confirmation modal.
- **Footer**: Clinic location details, Google Map embed placeholder, verified newsletter subscription with instant feedback, and quick links.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, keyframe animations, responsive design
- **JavaScript (ES6+)**: Vanilla JS for carousel, slider, form validation, intersection observer animations
- **Libraries**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/), [Font Awesome 6](https://fontawesome.com/)

## 🚀 Getting Started

Simply open `index.html` in your web browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```
